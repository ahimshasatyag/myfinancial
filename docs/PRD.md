# PRD (Product Requirements Document) - budgetku

## 1. Ringkasan Eksekutif
**budgetku** adalah aplikasi mobile manajemen keuangan pribadi (Personal Finance Management) modern yang dirancang dengan estetika *monochrome glassmorphism*. Aplikasi ini berfokus pada kecepatan, transparansi arus kas, alokasi anggaran, dan privasi penuh dengan enkripsi data dan PostgreSQL Row Level Security (RLS).

## 2. Fitur Utama
1. **Pencatatan Keuangan Multi-Akun**: Mendukung rekening bank, dompet tunai, dan e-wallet.
2. **Transaksi**: Pengeluaran, pemasukan, dan transfer antar akun tanpa inflasi laporan keuangan.
3. **Anggaran Fleksibel**: Alokasi plafon belanja berkala dengan pemantauan visual terpakai/sisa.
4. **Target Tabungan (Savings Goals)**: Perencanaan target tabungan terarah.
5. **Transaksi Berulang (Recurring)**: Penjadwalan otomatis pembayaran rutin/langganan.
6. **Laporan & Analisis**: Grafik tren arus kas dan komposisi pengeluaran per kategori.
7. **Privasi & Keamanan**: Mode sembunyikan saldo dan backup data JSON lokal.
